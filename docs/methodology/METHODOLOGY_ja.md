# RiskLens による信用リスクの読み方

言語：[EN](./METHODOLOGY.md) | [简中](./METHODOLOGY_zh-CN.md) | [繁中](./METHODOLOGY_zh-TW.md) | [日本語](./METHODOLOGY_ja.md)

RiskLens は、一般的な財務危機スクリーニングモデルに、財務指標、トレンド分析、コベナンツチェック、データ品質の警告を組み合わせます。結果の根拠を見える状態にしながら、初期レビューを速くすることが目的です。

結果は社内スクリーニング用のビューです。格付会社による信用格付け、デフォルト確率、融資推奨ではありません。

## 中心となる指標：Altman Z-Score

RiskLens は上場企業向けの Altman Z-Score を使用します：

`Z = 1.2 × X1 + 1.4 × X2 + 3.3 × X3 + 0.6 × X4 + 1.0 × X5`

| 項目 | 計算 | 主に示すもの |
|---|---|---|
| X1 | 運転資本 / 総資産 | 短期的な財務余力 |
| X2 | 利益剰余金 / 総資産 | 累積的な収益力 |
| X3 | EBIT / 総資産 | 資産の事業収益力 |
| X4 | 株式時価総額 / 総負債 | 市場価値による負債カバー |
| X5 | 売上高 / 総資産 | 資産回転効率 |

## リスクゾーンとインプライド格付け

| Z-Score | RiskLens ゾーン | インプライド格付け |
|---:|---|---|
| 4.50 以上 | Safe | AAA |
| 3.50–4.49 | Safe | AA |
| 2.99–3.49 | Safe | A |
| 2.50–2.98 | Grey | BBB |
| 1.81–2.49 | Grey | BB |
| 1.20–1.80 | Distress | B |
| 0.50–1.19 | Distress | CCC |
| 0.50 未満 | Distress | D |

インプライド格付けは RiskLens の表示尺度です。相対的なリスクを読みやすくするために一般的な格付け表記を用いていますが、S&P が発行または承認した格付けではありません。

## 1つのスコアだけで判断しない

RiskLens は40以上の指標も計算します：

- 流動性と短期支払能力；
- レバレッジと債務負担力；
- 収益性と事業パフォーマンス；
- 現金創出力とフリーキャッシュフロー；
- 資産と運転資本の効率性。

期間トレンドと同業比較により、リスクが改善しているか悪化しているか、また単一の入力に左右されていないかを確認できます。

## コベナンツチェック

インタレストカバレッジ、Debt/EBITDA、Debt/Equity、流動比率、当座比率、FCF/Debt の基準を設定できます。

設定したコベナンツは合格または違反として表示されます。必要な値を計算できない場合、RiskLens は手動確認が終わるまで違反として扱います。設定していない項目は確認対象になりません。

## データ不足の扱い

- 総資産、総負債、EBIT、売上高、運転資本のいずれかがない場合、Z-Score は `N/A` になります。
- 現在の実装では、利益剰余金または時価総額がない場合、その項目をゼロとして計算します。
- 過去時点の時価総額を取得できない場合、過去期間に現在の時価総額を使うことがあります。
- 結果を返す前に `NaN` と無限値を除去します。

これらはデータ品質上の制約として表示され、レビュー時に考慮する必要があります。

## 特に注意が必要な場合

金融機関、初期段階の企業、特殊な資本構成、会計処理や業界特性が元のモデル前提と大きく異なる企業では、Z-Score の代表性が低くなる場合があります。元の財務諸表、業界環境、流動性、株主、定性評価も併せて確認してください。
