# RiskLens 如何理解信用風險

語言：[EN](./METHODOLOGY.md) | [简中](./METHODOLOGY_zh-CN.md) | [繁中](./METHODOLOGY_zh-TW.md) | [日本語](./METHODOLOGY_ja.md)

RiskLens 將常用的財務困境篩選模型，與財務指標、趨勢分析、契約檢查和資料品質提示結合。目標是加快初步審閱，同時讓使用者看清結果背後的訊號。

最終結果是一種內部篩選視圖，不是評級機構的信用評級、違約機率或授信建議。

## 核心訊號：Altman Z-Score

RiskLens 使用上市公司版本的 Altman Z-Score：

`Z = 1.2 × X1 + 1.4 × X2 + 3.3 × X3 + 0.6 × X4 + 1.0 × X5`

| 項目 | 計算方式 | 主要反映 |
|---|---|---|
| X1 | 營運資金 / 總資產 | 短期財務緩衝 |
| X2 | 保留盈餘 / 總資產 | 累計獲利能力 |
| X3 | EBIT / 總資產 | 資產營運回報 |
| X4 | 股權市值 / 總負債 | 市值對負債的覆蓋 |
| X5 | 營業收入 / 總資產 | 資產週轉效率 |

## 風險區間與隱含評級

| Z-Score | RiskLens 風險區間 | 隱含評級 |
|---:|---|---|
| 4.50 及以上 | Safe | AAA |
| 3.50–4.49 | Safe | AA |
| 2.99–3.49 | Safe | A |
| 2.50–2.98 | Grey | BBB |
| 1.81–2.49 | Grey | BB |
| 1.20–1.80 | Distress | B |
| 0.50–1.19 | Distress | CCC |
| 低於 0.50 | Distress | D |

隱含評級是 RiskLens 的展示尺度。它借用常見評級標籤來協助理解相對風險，不是 S&P 發布或認可的評級。

## 不只看一個分數

RiskLens 另外計算 40+ 指標，涵蓋：

- 流動性與短期償付能力；
- 槓桿與債務承受能力；
- 獲利能力與營運表現；
- 現金創造與自由現金流；
- 資產與營運資金效率。

期間趨勢與同業比較有助於判斷風險正在改善或惡化，以及結果是否被單一輸入主導。

## 契約檢查

使用者可以設定利息覆蓋率、債務/EBITDA、債務/權益、流動比率、速動比率與自由現金流/債務的門檻。

每個已設定的契約都會顯示通過或違約。若指標無法計算，RiskLens 會暫按違約處理並提示人工覆核；未設定的契約不會參與檢查。

## 缺失資料如何處理

- 總資產、總負債、EBIT、營業收入或營運資金缺失時，Z-Score 顯示為 `N/A`。
- 目前實作中，保留盈餘或市值缺失時，該項按零計入。
- 歷史市值不一定能取得，因此歷史期間可能使用目前市值。
- 回傳結果前會清理 `NaN` 與無窮值。

這些情況會作為資料品質限制呈現，審閱結果時需要一併考慮。

## 哪些情況需要更謹慎

對金融機構、早期公司、特殊資本結構，以及會計處理或產業經濟特徵與原模型假設差異較大的企業，Z-Score 的代表性可能較弱。使用結果時，應同時檢視原始財報、產業背景、流動性、股東情況與定性分析。
