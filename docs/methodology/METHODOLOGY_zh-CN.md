# RiskLens 如何理解信用风险

语言：[EN](./METHODOLOGY.md) | [简中](./METHODOLOGY_zh-CN.md) | [繁中](./METHODOLOGY_zh-TW.md) | [日本語](./METHODOLOGY_ja.md)

RiskLens 把常用的财务困境筛查模型，与财务指标、趋势分析、契约检查和数据质量提示结合起来。目标是加快初步审阅，同时让用户看清结果背后的信号。

最终结果是一种内部筛查视图，不是评级机构的信用评级、违约概率或授信建议。

## 核心信号：Altman Z-Score

RiskLens 使用上市公司版本的 Altman Z-Score：

`Z = 1.2 × X1 + 1.4 × X2 + 3.3 × X3 + 0.6 × X4 + 1.0 × X5`

| 项目 | 计算方式 | 主要反映 |
|---|---|---|
| X1 | 营运资金 / 总资产 | 短期财务缓冲 |
| X2 | 留存收益 / 总资产 | 累计盈利能力 |
| X3 | EBIT / 总资产 | 资产经营回报 |
| X4 | 股权市值 / 总负债 | 市值对负债的覆盖 |
| X5 | 营业收入 / 总资产 | 资产周转效率 |

## 风险区间与隐含评级

| Z-Score | RiskLens 风险区间 | 隐含评级 |
|---:|---|---|
| 4.50 及以上 | Safe | AAA |
| 3.50–4.49 | Safe | AA |
| 2.99–3.49 | Safe | A |
| 2.50–2.98 | Grey | BBB |
| 1.81–2.49 | Grey | BB |
| 1.20–1.80 | Distress | B |
| 0.50–1.19 | Distress | CCC |
| 低于 0.50 | Distress | D |

隐含评级是 RiskLens 的展示尺度。它借用常见评级标签帮助理解相对风险，不是 S&P 发布或认可的评级。

## 不只看一个分数

RiskLens 还会计算 40+ 指标，覆盖：

- 流动性与短期偿付能力；
- 杠杆与债务承受能力；
- 盈利能力与经营表现；
- 现金创造与自由现金流；
- 资产和营运资金效率。

期间趋势和同业对比可以帮助判断风险是在改善还是恶化，以及结果是否被某个单一输入主导。

## 契约检查

用户可以设置利息覆盖率、债务/EBITDA、债务/权益、流动比率、速动比率和自由现金流/债务的阈值。

每个已设置的契约都会显示通过或违约。如果指标无法计算，RiskLens 会暂按违约处理并提示人工复核；未设置的契约不会参与检查。

## 缺失数据如何处理

- 总资产、总负债、EBIT、营业收入或营运资金缺失时，Z-Score 显示为 `N/A`。
- 当前实现中，留存收益或市值缺失时，该项按零计入。
- 历史市值并不总能取得，因此历史期间可能使用当前市值。
- 返回结果前会清理 `NaN` 和无穷值。

这些情况会作为数据质量限制展示，审阅结果时需要一并考虑。

## 哪些情况需要更谨慎

对于金融机构、早期公司、特殊资本结构，以及会计处理或行业经济特征与原模型假设差异较大的企业，Z-Score 的代表性可能较弱。使用结果时，应同时查看原始财报、行业背景、流动性、股东情况和定性分析。
