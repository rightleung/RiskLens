# RiskLens Full PDF 模版与草图（桌面导出优先）

> 目标：先把「可直接用于桌面导出」的 Full PDF 结构定下来，再进入实现。

## 1) 适用范围（Phase 1）

- 单公司 Full PDF（优先）
- 语言先跟随 UI（`zh-CN / zh-TW / en / ja`）
- 版式先按桌面阅读优化，再做移动端裁剪版

---

## 2) 页面与导出规格（建议）

- 页面尺寸：`A4 Landscape`（数据表页可读性更好）
- 页边距：`12mm`（上下左右一致）
- 基础网格：`12-column`
- 字体建议：`Inter + Noto Sans SC`
- 色彩：延续当前深色主题（深底 + 粉红风险色 + 青绿色安全色）
- 导出引擎建议：`Playwright page.pdf()`（HTML → PDF）

---

## 3) 期间与对比规则（按你确认的口径）

### A. 最新财报是季度（Quarter）

展示列固定为：

1. 最新季度（例：`25Q3`）
2. 去年同季度（例：`24Q3`）
3. `FY24`
4. `FY23`
5. `FY22`
6. 对比列 1：`25Q3 vs 24Q3`
7. 对比列 2：`FY24 vs FY23`

规则：

- 不展示 `24Q4` 这类“与最新季度不成对”的季度列
- 若同季缺失，则季度对比列显示 `--`，但年度列仍保留

### B. 最新财报是年度（FY）

展示列固定为：

1. `FY25`
2. `FY24`
3. `FY23`
4. `FY22`
5. 对比列 1：`FY25 vs FY24`
6. 对比列 2：`FY24 vs FY23`

## 4) Full PDF 模版（单公司）

## Page 1 — 封面与结论

- 公司名 + Ticker + 数据源 + 报告生成时间
- Altman Z-Score / 隐含评级（大号卡片）
- 一句话结论（安全/观察/风险）
- 目录（Page index）

## Page 2 — 风险摘要

- 优势（Top 3）
- 关注事项（Top 3）
- 数据质量摘要（缺失项数量、关键缺失）
- 评估口径说明（简版）

## Page 3 — Covenant 预检

- 指标 / 实际值 / 阈值 / 状态 / 信号 / 备注
- 失败项优先排序

## Page 4 — 核心 KPI 趋势表（重点页）

- 行：EBIT, EBITDA, 总债务, 债务/EBITDA, 利息保障倍数, FCF, FCF/债务, 流动比率
- 列：按第 3 节规则动态生成
- 样式：第一列指标名固定视觉强调（PDF 中不需要 sticky，但要高对比底色）

## Page 5 — 三大报表概览

- 利润表（摘要行）
- 资产负债表（摘要行）
- 现金流量表（摘要行）
- 每个报表保留“同比变化”小列

## Page 6-8 — 报表明细（按需分页）

- 利润表明细
- 资产负债表明细
- 现金流量表明细
- 同义项折叠提示统一为：`* 同义科目已折叠到主项，明细见附录映射。`

## Page 9 — 附录

- 指标定义与公式
- 同义项映射表（主项 ← 子项）
- 数据来源与免责声明

## 6) 实施切分（便于并行开发）

1. **数据层**：统一输出 `pdfPeriods` 和 `pdfComparisons`（前后端共用）
2. **模板层**：实现 `renderFullPdfHtml(reportData, locale)`
3. **导出层**：新增 `POST /api/v1/reports/pdf`，返回 PDF 文件流
4. **前端层**：公司卡片增加 `Export PDF`，先单公司
5. **验证层**：以 `AAPL / NIO / 0700.HK` 做快照对比

## 7) 验收清单（Phase 1）

- 季度最新时，列顺序严格为：`最新季度, 去年同季, FY-1, FY-2, FY-3`
- 不出现“孤立季度列”（如 `24Q4`）
- 对比列固定两组：`季度同比` + `年度同比`
- 关键页（Page 1 / 4 / 6）在 13~14 英寸笔记本预览中无挤压
- PDF 文件在 macOS Preview / Chrome 均正常分页显示
